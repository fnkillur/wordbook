# wordbook 설계 — 『Fluent Forever』식 간격 반복 학습 앱

(앱 이름은 임시. 폴더·저장소 이름도 나중에 바꿀 수 있다.)

## 왜 만드나

부부가 각자 외국어를 공부한다. 본인은 일본어, 배우자는 영어. 예전에 Anki 같은 앱을 쓰다가 **질려서** 그만뒀다.

이번에는 두 가지를 다르게 한다.

1. 가브리엘 와이너의 『Fluent Forever』 흐름을 충실히 따른다.
   - 번역 대신 그림과 소리로 익힌다.
   - 카드는 직접 만든다.
   - 간격 반복으로 복습한다.
2. 치이카와 세계관의 성취감 장치로 매일 열고 싶게 만든다.

## 쓰는 사람과 장면

- **하치와레(본인):** 일본어를 배운다.
  - 히라가나·가타카나를 읽고, 간단한 문장을 읽는다.
  - 기초 문법은 학원에서 배웠다.
  - 아는 단어는 먹다·마시다·걷다·놀다 수준으로 매우 적다.
  - 회화가 우선이다.
- **우사기(배우자):** 영어를 배운다. 수준은 조금 더 높지만 능숙하지는 않다.
- **기기:**
  - 하치와레는 안드로이드 앱(APK, adb 설치)을 쓴다.
  - 우사기는 아이폰 홈 화면 웹앱(PWA)을 쓴다.
  - 가계부 앱(`/Users/teo/Side/ledger`)과 같은 방식이다.
- **쓰는 때:**
  - 하치와레는 지하철 출퇴근 15분씩 쓴다. 한 손으로 쓰고, 소리를 못 켤 때가 있다.
  - 자기 전 30분 정도 볼 때도 있다.
  - 언제든 끊고 이어 보기가 기본이다.
- **카드 만들기:** 폰에서 짬짬이 한다.

## 목표

- 책의 순서를 따른다.
  1. 소리 구분
  2. 기초 단어 625개
  3. 문법을 실제 문장으로
  4. 빈도 1000 단어
  5. 관심 주제
- 카드는 사용자가 직접 만든다. 앱은 **기준 단어만 골라 주고**, 발음·읽기·뜻 같은 재료를 미리 채운다.
- 복습은 하루 목표 시간 안에서 끝난다. 앱이 새 카드 수를 조절해 복습이 감당 못 할 만큼 쌓이지 않게 한다.
- 공부가 치이카와 마을에서 '일하고 보수 받기'가 되어 모으고 꾸미는 재미가 있다.
- 두 사람의 마을은 하나다. 서로의 집에 놀러 가 볼 수 있다.

## 하지 않는 것

- 한자 쓰기·읽기를 따로 연습하지 않는다. 카드에 표기만 한다.
- 학습 데이터(카드·이미지·발음·복습 기록)를 서버에 두지 않는다. 폰 안에 두고 드라이브에 백업만 한다.
- 앱 안에 구글 이미지 검색을 통째로 넣지 않는다. 막혀 있고, 검색 API는 2027년 종료된다.
- 4단계 채점(다시/어려움/알맞음/쉬움)은 기본으로 두지 않는다.
- 공개 배포, 다른 사용자, 결제는 없다. 두 사람 개인용이다.

## 실패로 볼 것

- 매일 열기 싫어지는 것: 복습이 밀려 숙제처럼 느껴지거나, 보람이 없는 것.
- 카드 만들기가 번거로워 안 하게 되는 것: 이미지 넣기에 여러 단계가 걸리는 것.
- 지하철 한 손 사용이 불편한 것: 버튼이 멀거나 작은 것, 소리 없이 진행이 막히는 것.
- 폰을 바꾸거나 앱을 지웠을 때 카드가 사라지는 것.

## 정한 것 (사용자 결정)

### 첫 버전 범위

- **첫 버전:** 학습 + 마을 맛보기.
  - 625 단어 카드 만들기, 복습, 발음, 백업
  - 마을 화면, 보수, 도감, 놀러 가기 기본
- **다음 버전:** 방 꾸미기 세부, 소리 구분 단계, 문장 단계, 빈도 1000 단어. 하나씩 더해 가며 쓴다.

### 구조

- **탭:** 마을 · 단어장 · 도감 · 설정. 마을이 시작 화면이다.
- **마을(홈):**
  - 치이카와 세계 배경 위에 하치와레 집과 우사기 집이 나란히 있다. 두 사람 폰에서 같은 화면이다.
  - 아래에 "오늘 일하러 가기" 영역이 있다: 오늘 할 양(복습 n장 + 새 단어 n개), 진행 막대, 큰 **이어서 하기** 버튼.
  - 이 버튼 하나로 오늘 복습을 하고, 이어서 오늘 만들 단어로 넘어간다.
- 집을 누르면 그 사람이 꾸민 방이 열린다.
- **방 꾸미기:** 벽·바닥·선반 같은 **정해진 자리**에 아이템을 골라 놓는다. 자유 배치는 하지 않는다.

### 복습

- 앞면을 보고 떠올린 뒤 화면을 눌러 뒷면을 연다.
- 버튼은 **몰랐어요 / 알았어요** 두 개다. 엄지가 닿는 아래쪽에 둔다.
- 간격은 FSRS 계산법으로 앱이 조절한다.
- 소리가 켜져 있으면 뒷면을 열 때 발음이 나온다.
- **소리 없이 보기** 전환이 있다. 켜면 소리 카드는 뒤로 미룬다.
- 다크 모드를 지원한다(자기 전 사용).

### 카드 만들기

- 앱이 오늘의 단어를 순서대로 내준다.
- 각 단어에는 읽기(후리가나)·뜻·발음이 미리 채워져 있다.
- 이미 아는 단어는 **알아요**로 넘긴다. **건너뛰기**도 있다.
- **이미지**는 사용자가 직접 고른다.
  - '구글 이미지'를 누르면 그 단어로 검색한 구글 이미지가 열린다. 일본어 단어는 일본어로 검색한다.
  - 길게 눌러 **복사**하고 앱으로 돌아오면, 앱이 클립보드의 이미지를 알아보고 "넣을까요?"를 띄운다.
  - 안드로이드는 이미지 공유 대상으로 앱에 바로 보낼 수 있다.
  - 갤러리에서도 고를 수 있다.
- **나만의 기억 한 줄**은 선택이다.
- **단어 하나에서 만드는 카드:**
  1. 그림(+기억 한 줄) → 말하기
  2. 소리·글자 → 그림·뜻 떠올리기
  3. 소리만 듣고 떠올리기
- 영어에는 **듣고 쓰기(철자)** 카드를 선택으로 켤 수 있다. 기본은 끈다.
- 번역(우리말 뜻)은 기본으로 숨기고, 필요할 때만 볼 수 있다. *(빌더 판단으로 시작, 사용자 확인 필요)*

### 소리

- 기본 발음은 Google Cloud TTS로 만든다. 사용자가 **개인 구글 계정**에 결제 수단을 등록한 Cloud 프로젝트를 만든다(설정은 빌더가 안내). Apps Script와 같은 계정이다.
  - 카드를 만들 때 한 번 생성해 폰에 저장한다.
  - 비용은 두 언어를 다 해도 수 달러 이하로 예상한다. 무료 분량 안일 가능성이 높다.
- 원하면 Forvo 원어민 녹음(직접 찾아 넣기)이나 내 목소리 녹음으로 바꿀 수 있다.

### 문장 단계

- Tatoeba 예문(공개 라이선스)과 영화·드라마 자막 기반 단어 빈도로 쉬운 회화 문장 순으로 줄 세운다.
- "아는 단어 + 새 단어 하나"인 문장을 몇 개 제안하고, 사용자가 골라 카드(빈칸 채우기 중심)로 만든다.
- Core 2k/6k 같은 출처가 애매한 덱은 쓰지 않는다.

### 일본어 출발점

- **영어(우사기)도 625 단어부터** 시작한다. 아는 단어는 '알아요'로 빠르게 넘긴다. 소리 구분(r/l, f/p, b/v, 장단모음)은 짧게 넣는다.
- 가나는 건너뛴다.
- 장음·촉음·탁음처럼 귀로 구분할 소리만 짧게 다룬다.
- 본론은 625 단어부터다.
- 아는 문법은 문장 카드로 굳힌다.

### 성취감 (치이카와 세계관)

- **캐릭터:** 하치와레(본인), 우사기(배우자).
- **공부 = 일하러 가기:** 하루 목표를 채우면 보수를 받는다. 오래 붙잡고 있는 것보다 매일 채운 것에 보상한다.
- **모으기:** 보수로 음식·소품을 사서 **각자의 집**을 꾸민다. 모은 것은 **도감**에 쌓인다.
- **자격증:** 풀 뽑기 검정처럼 익힌 단어 수에 따라 급수가 오르고, 오를 때 특별한 것을 받는다.
- **짧은 축하:** 단어 몇 개마다 캐릭터가 잠깐 나와 축하한다.
- **놀러 가기:**
  - 마을에서 상대방 집을 누르면 그 사람이 꾸민 방을 구경한다. 내 방만 꾸밀 수 있다.
  - 마을에서 오늘 공부를 마쳤는지가 살짝 보인다(예: 마친 캐릭터는 집 앞에 나와 있다).
- **이미지:** 치이카와 이미지는 **사용자가 준 것만** 쓴다. 내려받지 않는다. 개인용이다.

### 저장과 서버

- **폰 안:** 카드·이미지(줄여서 저장)·발음·복습 기록. 625 단어 기준 100MB 안쪽.
- **아이폰:** 홈 화면 웹앱으로 쓰게 안내한다. 사파리 탭은 오래 안 쓰면 데이터가 지워질 수 있다.
- **Apps Script 하나**(가계부와 같은 방식, 별도 프로젝트):
  - TTS 요청 대리. 키는 서버에만 둔다.
  - 구글 드라이브 백업: 하루 한 번, 또는 직접 누를 때. 파일 하나로 내보내기·가져오기도 지원한다.
  - **마을 데이터**: 사람별 모은 아이템·방 배치·자격증 급수·보수·최근 공부 여부. 앱을 열 때와 공부를 마칠 때 주고받는다.

## 빌더 판단 (내가 정한 것, 문서 검토 때 확인)

- **백업:**
  - 기본 안전장치는 **파일 하나로 내보내기·가져오기**다.
  - 드라이브 백업은 Apps Script를 거쳐 **사용자(하치와레) 개인 드라이브**의 사람별 폴더에 올린다. 우사기 백업도 같은 드라이브에 들어간다.
  - Apps Script의 요청 크기·6분 제한 때문에 한 번에 올리지 않는다. 카드 데이터 JSON과 이미지·소리 파일을 **바뀐 것만 하나씩** 올린다.
- **아이폰 이미지 붙여넣기:** 홈 화면 웹앱은 돌아왔을 때 클립보드를 스스로 읽을 수 없다. 그래서 아이폰은 '이미지 붙여넣기' 버튼을 한 번 누르고 사파리의 '붙여넣기' 확인을 거친다. 안드로이드는 앱이 알아서 묻고, 공유로도 받는다.
- **뜻은 우리말로:** 일본어 단어의 뜻은 JMdict 영어 풀이 대신 **우리말**로 준비한다(빌더가 만들고, 사용자가 카드 만들 때 고칠 수 있다).
- **문장 단계 데이터:** 다음 버전에서 만든다. 일본어 문장의 단어 나누기는 빌드할 때 미리 해서 앱에 색인으로 넣는다. 지하철에서도 인터넷 없이 제안이 동작한다.

- **기술:** 가계부와 같은 스택(React 19 + Vite + TypeScript, Dexie, Capacitor 안드로이드, Vitest, oxlint, pnpm).
  - 위치는 `/Users/teo/Side/wordbook`, 개인 GitHub 저장소.
  - 웹은 GitHub Pages.
- **데이터 준비(빌더 담당):**
  - 625 기초 단어: 책 저자가 공개한 영어 기준 목록과 주제 분류를 쓴다.
  - 일본어 대응 단어·읽기·뜻: JMdict(공개 라이선스)와 빈도 자료로 고르고, 사용자가 만들기 전에 고칠 수 있게 한다.
  - 영어 단어의 우리말 뜻: 빌더가 준비한다.
  - 빈도 1000: 자막 기반 빈도 목록.
- **하루 목표 시간:** 기본 15분, 사람마다 바꿀 수 있다. 새 카드 수는 최근 복습 부담을 보고 조절한다.
- **보수·가격·급수 기준:** 빌더가 정하고, 써 보며 조정한다.
- **화면 세부:** 배치, 색, 애니메이션(축하 연출은 가계부 축하처럼 짧게).

## 제약

- 실명은 코드·문서·커밋에 넣지 않는다. 캐릭터 이름으로만 쓴다.
- 비밀값(토큰·엔드포인트·스크립트 ID·TTS 키)은 저장소·웹 빌드에 넣지 않는다.
- 커밋은 사용자 검토 후, 웹·서버 배포는 사용자가 요청할 때만 한다.
- 개인 GitHub 계정을 쓴다. 회사 계정·토큰과 섞지 않는다.
- 치이카와 이미지는 사용자가 준 것만 쓴다.
