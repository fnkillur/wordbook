# 빈칸 문장 카드 설계

## 왜 만드나

플루언트 포에버는 기초 단어 다음 단계로 단어를 **문장 속에서** 다시 꺼내 쓰는 연습을 권한다. 그림 카드로 뜻을 붙인 단어를, 실제 회화 문장의 빈칸으로 떠올리게 해서 쓰임새와 자연스러운 속도의 발음에 익숙해지게 한다. 이 앱의 회화 빈도 단어(1~1,000위)마다 문장을 하나씩 골라 두었고(`scripts/data/sentences-<lang>.txt`), 이걸 복습 카드로 만든다.

## 목표

- 회화 빈도 단어에 빈칸 문장 카드를 붙인다. 앞면은 빈칸 문장과 내 그림, 뒷면은 채운 문장과 원어민(또는 Chirp 3 HD) 음성.
- 안드로이드 앱과 웹앱 모두에서 일본어·영어 빈칸 카드를 쓸 수 있다.
- 원어민 녹음이 있는 문장은 녹음을, 없는 문장은 TTS 음성을 쓴다.

## 하지 않는 것

- 기초 625 단어의 빈칸 카드(문장 데이터가 없다).
- 사용자가 문장을 고르거나 고치는 기능. 문장은 데이터 파일로만 정한다.
- 번역을 기본으로 보여 주는 것(플루언트 포에버는 번역 없이 그림으로 기억한다).

## 실패로 보는 것

- 단어를 처음 보는 날 그림 카드와 빈칸 카드가 같이 나와 한 번에 모르는 것이 둘이 되는 것.
- 빈칸 카드가 같은 단어의 다른 카드 바로 앞뒤에 나와 답을 알려 주는 것.
- 녹음을 받지 못해 소리가 안 나는데 카드가 나와서 막히는 것.

## 정한 것

### 데이터

- 문장 파일 `scripts/data/sentences-ja.txt`, `sentences-en.txt`. 한 줄: `순위|[빈칸]을 감싼 문장|우리말 번역|출처`.
  - 출처: 일본어 `K`(Kaishi 1.5k), `I<id>`(ImmersionKit 대사), `self`. 영어 `D`(DailyDialog), `T<id>`(Tatoeba), `self`.
  - `K`·`I`·`T`는 원어민 녹음이 있다. `D`·`self`는 없다.
- `scripts/build-words.mjs`(또는 새 스크립트)가 문장 파일을 읽어 앱 데이터에 넣는다. 단어 하나에 문장 하나. 형태는 빌더가 정하되, 화면에 필요한 값은 빈칸 앞·빈칸 말·빈칸 뒤, 번역, 녹음 파일이 있는지(경로)다.
- 일본어 문장 파일에는 다섯째 칸으로 빈칸 말의 읽기(히라가나)를 더한다. 채우는 건 데이터 준비 단계에서 형태소 분석(fugashi)으로 만들고 사람이 훑어 고친다(learn 파일의 고친 읽기와 같은 방식). 빌드 스크립트는 읽기 칸이 비었거나 가나가 아니면 멈춘다. (설계자 판단.)
- 학습 목록(learn 파일)에서 뺀 단어는 문장도 없다. 문장 파일에 없는 단어는 빈칸 카드를 만들지 않는다.
- 문장 데이터와 녹음은 모두 공개 저장소에 커밋하고 웹 빌드에도 넣는다(사용자 결정, 2026-11-09). 출처는 `scripts/data/SOURCES.md`에 적었다.

### 녹음 파일

- 원어민 녹음을 미리 받아 `public/` 아래(예: `public/sentence-audio/<lang>/<순위>.mp3`)에 넣는다. 안드로이드는 앱 안에 들어가고, 웹은 같은 주소에서 필요할 때 한 파일씩 받는다.
- 받는 곳
  - Kaishi: 받은 덱 `Kaishi.1.5k.v2.4.3.apkg`(GitHub donkuri/Kaishi 릴리스) 안의 문장 음성. 덱의 media 목록은 zstd로 압축된 protobuf다. 문장 음성 파일 이름은 노트의 `Sentence Audio` 필드 `[sound:...]`에 있다.
  - ImmersionKit: `https://immersionkit.s3.bhs.io.cloud.ovh.net/media/<분류>/<작품 표시 제목>/media/<sound 파일>`. 표시 제목은 슬러그(`my_neighbor_totoro`)가 아니라 `My Neighbor Totoro` 같은 제목이다(사이트 스크립트가 슬러그→제목 표로 바꾼다). 검색 API는 `https://apiv2.immersionkit.com/search?q=<단어>`이고 결과 `examples[]`에 `id`, `sound`, `title`이 있다.
  - Tatoeba: 문장 번호별 음성(`https://tatoeba.org/audio/download/<audio id>` 등, 정확한 주소는 빌더가 확인).
- 파일이 커지지 않게 단일 채널·낮은 비트레이트로 다시 인코딩한다(목표: 한 문장 20KB 안팎). ImmersionKit 원본은 한 개 60KB쯤이다.
- 녹음을 받는 스크립트는 저장소에 넣는다(`scripts/`). 원본 덱·검색 결과는 넣지 않는다.

### 카드가 생기는 때

- 새 카드 종류 `cloze`를 추가한다.
- 단어를 만들 때는 만들지 않는다. 그 단어의 카드 하나를 처음으로 "알았어"로 답했을 때 `cloze` 카드를 만든다. 이미 있으면 다시 만들지 않는다.
- 만든 카드의 기한은 **다음 날 0시(기기 시간)**로 둔다. 같은 날 학습 화면을 다시 열어도 나오지 않는다. 그날 할 양 계산에도 들어가지 않는다. (설계자 판단: "처음 보는 날 둘이 같이 나오지 않게"를 지키려고.)
- 문장이 없는 단어(기초 625, 뺀 단어)는 만들지 않는다.
- 이미 공부 중인 단어(이 기능 전에 만든 단어 중 "알았어"를 받은 적 있는 것)도 다음에 한 번 "알았어"를 받으면 생긴다. 한꺼번에 몰아서 만들지 않는다.

### 음성

- 문장 음성은 `cloze` 카드가 생길 때 준비한다. 학습하지 않는 단어의 음성은 만들지 않는다.
  - 녹음이 있으면 앱에 든 녹음 파일을 읽어 저장한다(인터넷 없이 된다).
  - 없으면 지금 단어 발음처럼 Apps Script TTS(일본어 `ja-JP-Chirp3-HD-Puck`, 영어 `en-US-Chirp3-HD-Aoede`)로 만든다. 받지 못했으면 지금 단어 발음처럼 나중에 다시 받는다.
- 단어 발음과 문장 음성은 따로 저장한다(미디어 종류를 하나 더 두는 식). 백업 파일에도 담는다.
- 음성이 아직 없는 `cloze` 카드는 소리 없이도 풀 수 있으므로 오늘 할 카드에서 빼지 않는다. 뒷면에서 재생만 못 한다.
- 설정 "소리 없이 보기"를 켜면 자동 재생하지 않는다.

### 화면

- 앞면
  - 빈칸 문장. 빈칸은 밑줄 같은 빈 칸으로 보이고 길이는 답 글자 수와 상관없이 일정하다(길이로 답을 짐작하지 않게).
  - 그 단어에 내가 넣은 그림이 있으면 함께 보인다. 없으면 문장만.
  - "번역 보기"를 누르면 우리말 번역이 나온다. 누르기 전에는 보이지 않는다. 카드가 바뀌면 다시 가려진다.
  - 소리 버튼은 앞면에 두지 않는다(문장을 들으면 답이 나온다).
- 뒷면
  - 빈칸을 채운 문장. 채운 말은 강조한다. 일본어는 채운 말의 **문장에 나온 꼴 그대로의 읽기**를 함께 보여 준다(`分かりませんでした` → わかりませんでした).
  - 문장 음성을 자동 재생하고, 소리 버튼으로 다시 듣는다.
  - 번역은 계속 "번역 보기"로만 본다.
- 하치와레 말풍선 질문은 카드 종류별 문구 목록에 `cloze`용을 더한다(예: "빈칸에 들어갈 말은?"). 친근한 반말.
- 학습 화면의 책 페이지 모양, 몰랐어/알았어 버튼, 반응·보수는 다른 카드와 같다.

### 순서

- 같은 단어의 카드끼리는 연달아 내지 않는 지금 규칙에 `cloze`도 들어간다.
- 카드 종류 순서는 기존 종류 뒤에 `cloze`를 둔다.

## 빌더에게 맡기는 것

- 단어 데이터에 문장을 붙이는 형태(같은 JSON에 넣을지 따로 둘지), 컴포넌트를 어떻게 나눌지.
- 녹음 재인코딩 도구와 설정, 받는 스크립트의 모양.
- 미디어 키 이름과 저장 방식, DB 버전 올리는 방식.
- 빈칸·강조의 정확한 모양(책 페이지 디자인에 맞게).
- 오래된 녹음 주소가 바뀌어 일부를 받지 못하면 그 문장은 녹음 없음(TTS)으로 바꾸고 목록을 남긴다.
