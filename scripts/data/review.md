# 단어 데이터 확인 목록

애매해서 하나를 골라 둔 것들. 카드를 만들 때 바꿀 수 있지만, 미리 보고 고칠 게 있으면 `words.txt`를 고친 뒤 `node scripts/build-words.mjs`를 다시 돌린다.

## 같은 읽기·같은 글자를 쓰는 짝 (그림과 기억 한 줄로 구분)
- moon / month: 둘 다 月(つき). month는 ひと月로 바꿀 수도 있다.
- high / expensive: 둘 다 高い(たかい)
- see / watch: 見る / 観る (둘 다 みる)
- fly / jump: 飛ぶ / 跳ぶ (둘 다 とぶ)
- write / draw: 書く / 描く (둘 다 かく)
- hear / listen: 聞こえる / 聴く
- old: 古い(물건) / 年を取った(사람)
- light: 光(빛) / 軽い(가벼운) / 明るい(밝은)
- back: 背中(몸) / 後ろ(방향)
- foot: 足(몸) / フィート(길이)
- leg: 脚(あし) — foot의 足와 읽기가 같다
- fan: ファン(사람) / 扇風機(선풍기)
- sex: セックス(행위) / 性別(성별)
- race: 人種(인종) / 競走(경주)
- sign: 看板(표지판, 명사) / 署名する(서명하다, 동사)

## 고른 뜻
- bill → 請求書(청구서). 지폐로 보려면 お札(おさつ).
- court → 裁判所(법원). 운동 코트는 コート.
- card → カード, note → メモ, lock → 錠(じょう, 자물쇠). 일상어로는 鍵(かぎ)도 쓴다.
- country → 国, store/shop → 店, street/road → 道
- 4 → よん, 7 → なな (し·しち도 있다). 4월은 しがつ, 7월은 しちがつ, 9월은 くがつ.
- you(복수) → あなたたち. 실제 회화에서는 잘 안 쓴다.
